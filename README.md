# Fairy · 考研学习作战台

> 把一张 xlsx 计划表，变成一个能打勾、会翻页、能计时的每日作战台。
> **零依赖 · 单文件 · 数据全在本地 · 双击即用。**

Fairy 是一个面向考研（以及任何长周期备考）的每日执行终端。你把排好的计划表丢进去，
它会把它拆成每天一条条的时间轴，告诉你**此刻该干什么、今天还欠多少、这一周落后了没**；
打过的勾会一直留着，关掉网页、关掉电脑，第二天打开还在。

## 这是什么

大多数备考计划最后都死在同一个地方：**计划表很完美，执行是另一回事。**
表格能告诉你"周三要学线代第 5 章"，但它不会告诉你现在几点、该先做哪一件、
这一周还欠几项没打卡、上次那件事做完了没有。

Fairy 补的就是这一段。它不是一个"计划表查看器"，而是一个**执行看板**：

- 你导入的每一周，都会变成左侧一张有状态和完成率的周卡片；
- 每天的时间轴是按真实时间刻度画的，冲突的安排会自动分列，互不遮挡；
- 顶部的**作战日历**可以收成一周、展开成一个月，逾期未完成的条目会直接标在日期上；
- 勾一下就完成，完成率会实时流进统计和番茄钟的时长曲线。

**所有数据都存在你自己的浏览器里**，不上传任何服务器，断网也能用。
导出的 xlsx 可以直接用 Excel / WPS 打开，勾选状态会原样写回去。

## 30 秒上手

1. 拿到 `Fairy.html`（单文件，双击即用，不需要安装任何东西）。
2. 用浏览器打开它。
3. 点右上角 **「导入计划」**，选择你的 xlsx 计划表；可以一次框选多个文件。
4. 页面上出现周卡片、时间轴、邦布——开始打勾。

没有计划表？仓库里有三份现成的东西：

| 文件 | 用途 |
|---|---|
| `app/计划表模板.xlsx` | 空白模板，照着填 |
| `app/示例_第06周计划.xlsx` | 演示数据：完整一周，10/18 那天专门演示冲突分列与同时段叠行 |
| `app/计划表导入格式_提示词.md` | 把这段提示词丢给任意 AI，让它按 Fairy 的格式生成计划表 |

> 仓库托管版本不收录二进制资源（xlsx 模板、界面截图、编译产物），

## 功能介绍

### 1. 一次导入整份文件，多周自动合并

一个 xlsx 里可以放任意多周的计划。Fairy 会把文件里所有周总表和它们的日期子表
一次性认出来并加载，不必一周一周导。

**重合的日期会自动合并**，规则是三级的：

- 先按**周 id** 对齐，同一周的条目进同一格；
- 再按 **时间段 + 科目** 对齐，同槽位的内容取更详细的那一版；
- 完成状态用「任一为完成即视为完成」合并——**所以重复导入不会膨胀，也不会把你已有的打卡冲掉。**

### 2. 作战日历：收起是周历，展开是月历

首页顶部原本是一块「今天要处理」，现在换成了**作战日历**：

- **收起态**是一行七天的胶囊，每格显示日号、星期、一只邦布、完成度条，
  以及该日**逾期未完成的条数**（红色角标）；
- 点「展开」变成**整月网格**，可以左右翻月，每天的底色表示完成度（灰=未开始 / 黄=进行中 / 绿=已完成）；
- 任何时候点任意一天，都切到那天的作战视图，跨周会自动跟着换周。

日历、首页时间轴、「本周每日一览」三处共用同一份"当前日期"状态，点哪儿都同步。

### 3. 每日时间轴：真实刻度 + 冲突自动分列

时间轴按**分钟**为刻度绘制，块高与真实时长成正比。一天内安排重叠时：

- 无冲突的条目**独占整行**；
- 重叠的条目**均分成最多 4 列**并排；
- **起止时间完全相同**的条目会合成一块，上下叠行显示（而不是压在一起）；
- 超过 4 条挤在一起时，第 4 列会标出溢出数量。

窄屏下用 CSS 容器查询做自适应：块太窄时先隐去"掌握目标"，再隐去时间，最后隐去勾选框。

### 4. 本周每日一览：每天一只不同的邦布

一周七天各配一只不同的邦布，蹲在自己的黑色小盘子里；
**切到下一周会自动换一批**（内置 15 只循环使用）。当天全部完成时，盘子变成绿底打勾。

### 5. 目标与统计

- **四科冲分目标**：每科的目标分、得分构成、完成状态；
- **本周各科目标**：来自周总表的小目标；
- **统计页**：各科完成率、完成率走势、学习时长分布。

### 6. 计划管理

每次导入算一个「批次」。计划管理页按 4 行 × 2 列分页展示所有批次，
可以**删掉整份计划**或只删其中一周，删完立刻从看板和统计里消失。

### 7. 番茄钟

- 25 分钟学习 / 5 分钟休息，环形进度显示，时长可改；
- 科目可自定义，点击标签切换当前科目；
- **小组件**可以单独开一个窗口、可拖动、可调三档大小，并且能**保持在所有窗口最上层**；
- 到点柔和闪烁提醒（音频提醒暂未启用）。

### 8. 外观

顶栏「外观」按钮打开右侧抽屉：

- 自选**本地图片**做背景，自动压缩后存到本地；
- **卡片不透明度**滑块，背景能透出来，正文对比度不受影响；
- 背景亮度、暗度遮罩、模糊四个实时滑块；
- 一键恢复默认。

### 9. 导出与备份

- **导出 xlsx**：每天一个 sheet，勾选状态用 √ / □ 写回，与原计划表同构；
- **备份 JSON**：把全部数据导出成一个文件，在另一台设备上「从备份恢复」即可搬家。

## 使用说明

### 界面与操作

| 区域 | 能做什么 |
|---|---|
| 顶栏 | 导入计划 / 导出表格 / 备份 / 外观 |
| 顶部时间条 | 当前时间、此刻正在执行的任务、前后一件 |
| 作战日历 | 切日期、展开月历、查看逾期 |
| 左侧周列表 | 切换周；每张卡显示状态与本周完成率 |
| 周横幅 | 周序号、阶段、本周主题、关键节点 |
| 日期导航 | 前一天 / 后一天 / 回到今天 / 跳到指定日期 |
| 统计行 | 今日完成率、距初试天数、累计条目 |
| 每日时间轴 | 点任意一行即可完成 / 取消 |
| 本周每日一览 | 点某天切换日期；显示当天完成情况 |

**快捷键**：页面底部 Tab 栏在「作战 / 目标 / 统计 / 计划 / 番茄」之间切换。

### 数据存在哪

全部存在**当前浏览器**的 `localStorage` 里：

- 主数据键：`arknights_kaoyan_ops_v2`（周计划、打卡、番茄钟记录）
- 外观设置键：`fairy_skin_v1`（背景图与不透明度，单独存放以免撑爆主数据配额）

因此：

- 换浏览器 / 换设备 → 用「备份」导出 JSON，再在另一端「从备份恢复」；
- 清理浏览器数据会一并清掉打卡记录，重要计划请定期备份；
- 无痕窗口的存储是临时的，关闭即失效。

### 隐私

不联网、不上传、不打点。唯一会访问外部网络的动作是你自己点开外部链接时。
背景图和计划表始终留在本机。

## 计划表格式

Fairy 认的是一种很朴素的结构：**一份 xlsx 里，每一周 = 一张周总表 + 七张日期子表**。

### 周总表（4 列）

行序固定：

```
标题            （如「第 06 周」）
阶段            （基础 / 强化 / 冲刺 …）
一、本周主题
二、四科冲分目标
    科目 | 目标分 | 得分构成 | 完成情况      × 4 行
三、各科目标
    科目 | 目标 | 完成情况                    × 4 行
四、每日一览
    日期 | 星期 | 重点 | 完成                 × 7 行
五、关键节点
六、材料建议
```

> 「完成情况」列的位置不固定，解析器按**表头关键字**定位，不依赖列号。

### 日期子表（5 列）

第 3 行是固定表头：

```
时间段 | 科目 | 学习内容 | 掌握目标 | 完成情况
```

最后一行是「今日复盘」。

### 归属规则

子表归属**靠 sheet 顺序**：一张周总表后面紧跟的七张日期子表属于它，
子表名形如 `10-18 周日`（只用于显示，不参与解析）。

### 硬性约束

- 单元格内容里**不能出现半角竖线 `|`**；
- 科目只能取 `数学 / 英语 / 政治 /专业课 / 生活 / 休息 / 复盘`；
- `生活` 与 `休息` 不计入完成率；
- 子表里的时间写成 `08:00-10:00` 这样的区间。

完整的字段说明和一份可以直接喂给 AI 的提示词见
[`app/计划表导入格式_提示词.md`](app/计划表导入格式_提示词.md)。

## 技术实现

这个项目刻意**不引入任何第三方运行时依赖**，包括解析 xlsx 用的库。

- **自写 ZIP / xlsx 解析器**：手写 ZIP 中央目录解析与 CRC32 校验；
  浏览器端用原生 `DecompressionStream('deflate-raw')` 解压，Node 端换 `zlib.inflateRawSync`——
  **同一套解析函数两端共用**。
- **自写 xlsx 导出器**：用 STORED（不压缩）方式自己拼 ZIP 包，每天一个 sheet，
  勾选状态以 √ / □ 写回，导出文件用 Excel 和 WPS 都能正常打开。
- **单文件交付**：所有 CSS / JS / 图标 / 背景全部 base64 内联，产物零外链，
  双击就能用，放进 U 盘、发给同学、发到任何地方都不会丢样式。
- **剥离式静态检查器**：逐字符扫描先把注释、字符串、正则字面量剥掉再做符号分析，
  这样"未定义函数"这类检查不会把注释里的字当成代码误报。
- **真实浏览器验收**：用无头浏览器跑端到端检查，其中一项用 `getComputedStyle`
  实测渲染色，把半透明背景按 alpha 逐层合成后算亮度和对比度，
  防止出现"白底白字"这种肉眼才发现的问题。

### 视觉

- 主色 `#2B6BE4` 电光蓝，强调色 `#FFE500` 明黄，底色 `#0A0A0A`；
- 面板使用 45° 切角几何，标题 900 字重加描边，正文 700；
- 动效统一走 `cubic-bezier(.34,1.56,.64,1)` 回弹曲线，并尊重 `prefers-reduced-motion`。

## 开发与构建

### 目录

```
Fairy/
├─ src/                源码
│   ├─ ops.js          xlsx 解析 / 合并 / 导出 / 时间轴布局（纯函数）
│   ├─ ops-app.js      应用层：渲染、交互、番茄钟、计划管理、外观
│   ├─ ops-page.html   页面骨架（占位符由构建脚本注入）
│   ├─ zzz-theme.css   主题层
│   ├─ base_style.css  基础样式
│   ├─ build-ops.js    组装 + 冒烟检查
│   └─ paths.js        路径总表
├─ test/               7 套测试
├─ tools/              素材与示例生成脚本
├─ desktop/            Electron 桌面版（main / preload / 打包脚本）
├─ app/                使用说明、计划表模板与提示词
└─ docs/screenshots/   界面截图
```

### 构建单文件

```bash
cd src
node build-ops.js            # 发行版：dist/Fairy.html，零第三方素材
node build-ops.js --skin     # 自用版：额外内联官方背景皮肤
```

### 跑测试

```bash
cd src
node test-static.js          # 检查器自测
node test-ops.js             # 引擎单测
node build-ops.js            # 构建 + 冒烟检查
node e2e-ops.mjs             # 真实浏览器端到端
node test-panels.mjs         # 各面板交互
node test-mini.mjs           # 置顶小组件
node test-skin.mjs           # 外观系统
node test-desktop.mjs        # Electron 桌面版
```

端到端测试需要本机装有 Edge（Playwright 走 `channel: 'msedge'`），
桌面版测试需要 `desktop/` 下的 `npm install` 依赖。
