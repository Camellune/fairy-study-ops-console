# 交付说明

**Fairy** · 考研学习作战台。这个文件夹里是全部可直接使用的东西，验收看这里就够了。

---

## 一、有什么

| 文件 | 是什么 | 怎么用 |
|---|---|---|
| `Fairy.html` | 网页版·**发行版**（单文件，离线可用） | 双击，用浏览器打开 |
| `Fairy_本地版.html` | 网页版·**本地版**（自带默认皮肤） | 双击打开；适合自己长期用 |
| `Fairy_桌面版\Fairy.exe` | 桌面版（免安装，含默认皮肤） | 双击打开；整个目录要一起留着 |
| `计划表模板.xlsx` | 空白计划模板 | 排计划用，或给 AI 当格式基准 |
| `示例_第06周计划.xlsx` | 演示数据：完整一周（10/18-10/24） | 导入它，里面 10/18 那天专门演示了冲突布局 |
| `计划表导入格式_提示词.md` | 让 AI 生成合规计划的提示词 | 整段复制给 AI，按它问的填 |
| `使用说明.md` | 本文件 | — |

三个版本的数据**互不相通**（各自存在自己的本地存储里）。要搬数据，用页面顶部的「备份」导出 JSON，再到另一个版本里「恢复」。

> **发行版 vs 本地版**：功能完全一样，唯一区别是「内置皮肤」这一张图。
> 发行版**不打包任何第三方图片**，分发给别人时干净；本地版把这张图内嵌进单文件里，
> 打开就有默认背景。**两边都带完整的皮肤接口**，换成自己的图、调整不透明度在哪个版本都能做。

---

## 二、三分钟上手

1. 双击 `Fairy.html`（或桌面版的 `Fairy.exe`）。
2. 点右上角「导入计划」，选 `计划表模板.xlsx` 或你自己的计划文件——支持一次选多个。
3. 左边选周，顶部选日期，右边就是当天的时间轴。
4. 点任务块就是打卡，自动保存，关掉再开还在。

第一次打开页面是空的，这是正常的（它不预置假数据，免得污染你的真实记录）。导入一次就有内容了。

## 三、六个页签

底部有六个页签，从左到右：

| 页签 | 干什么 |
|---|---|
| 作战 | 今天该做什么（时间轴 + 待办 + 目标） |
| 日历 | 整月总览，点哪天跳哪天 |
| 目标 | 四科冲分目标、本周各科目标 |
| 统计 | 科目分布、完成率走势 |
| 计划 | **计划管理**：看有哪些计划、删掉不要的 |
| 番茄 | **番茄钟**：计时、统计各科学习时长 |

### 计划管理怎么用

进去是一块一块的卡片（每行两块），每块 = **你导入的一份计划**。块上写着：

- 这份计划覆盖的日期范围（例：10月18日 - 10月24日）
- 几周、几天
- 导入时间

**删计划有两种粒度**：

- 块**右上角的 ×** → 删掉这整份计划（它带来的所有周都会消失）
- 点开块 → 下面列出这份计划的每一周，每行右侧有「删除这周」→ 只删这一周

删除前会弹确认框，写清会删掉几周几天，避免误操作。删掉后番茄钟的统计**不会**跟着丢。

> 想删掉我给的那个示例周？就是这个入口：计划页 → 点块 → 「删除这周」，「×」则是连整份一起删。

### 番茄钟怎么用

- 默认 **25 分钟学习 + 5 分钟休息**，四个科目默认是 数学 / 专业课 / 英语 / 政治，点「改名」可以改成你自己的叫法
- 点「开始」就计时，走完自动记一轮、响一声、切到休息；休息走完停下等你开始下一轮
- 每轮的学习分钟数按当前科目累计，底部饼图就是各科占比，图例里同时给累计和今日
- 中途「跳过」= 结束当前阶段；**不足 1 分钟不计入统计**，避免刷数据
- 右下角可以开一个**悬浮小组件**：显示剩余时间和科目，能直接在小组件上开始/暂停；拖顶部小横条可以挪位置；小/中/大三档尺寸
- **右侧有个圆形番茄按钮**（不随页面滚动）：任何页面点一下都能进番茄钟；计时中它外圈会脉冲
- **倒计时结束会柔和闪烁 5 次**（约 4.5 秒）：小组件、圆环、时间数字、右侧按钮同时闪，切到别的界面也能注意到。暂不发声
- **桌面版专用：勾选「保持在顶部」会弹出一个独立的置顶小窗**。它有这几件事是网页版做不到的：
  - 永远浮在所有窗口最上层（连全屏的浏览器、PDF、视频播放器都盖不住它）
  - 不出现在任务栏，不占 Alt+Tab
  - 拖顶部小横条能挪位置，拖边缘能改大小
  - 和主窗口的计时状态实时同步，任何一边点开始/暂停，另一边跟着变

## 四、外观与皮肤

顶栏右上角有个**调色盘图标「外观」**，点开是右侧滑出的抽屉，所有外观设置都在里面：

| 位置 | 能调什么 |
|---|---|
| 背景图 | 「选择图片」用你自己的图当背景；「内置皮肤」换成本地版自带的图；「清除」改成纯黑底 |
| 背景亮度 | 20%–140%，照片太亮就往下压 |
| 暗度遮罩 | 0%–95%，往上加相当于给背景蒙一层黑，保证正文永远看得清 |
| 背景模糊 | 0–24px，把大图虚化当氛围用 |
| 卡片不透明度 | 30%–100%，调低后能透出背后的画面 |

**几个说明：**

- 选图会**自动压缩**（最长边 1920、转 JPEG），不会把浏览器存储撑爆；原图不会离开你的电脑，也不上传任何地方。
- 外观设置单独存在一个键里，**和打卡数据分开存**。就算图片大到存不下，也只是外观回落，不会把你的打卡记录弄丢。
- 发行版里「内置皮肤」是**灰色不可点**的（因为它不打包第三方图片），但「选择图片」照常能用——皮肤接口对所有人开放。
- 恢复默认外观：抽屉最下面那个按钮。
- 本地版里的内置皮肤是《绝区零》官方素材，**版权归米哈游所有**，只供本机个人使用，不随发行版分发。

## 五、时间轴怎么读

- 左边是时间刻度，从上到下；块的**高度 = 时长**
- 没有冲突的任务占满整行
- 时间有重叠 → 自动并成两列（最多 4 列），各占一半宽
- 起止时间**完全相同** → 不拆列，合成一个块，块内上下叠行（最多 4 行）
- 超过 4 个并行 → 多出来的塞进第 4 列，标虚线框，数据不会丢
- 窄屏（手机）会自动收起次要信息，鼠标悬停能看到完整内容

导入 `示例_第06周计划.xlsx`，切到 **10月18日** 就能直接看到上面几种情况（同时段叠行、部分重叠分列、独占整行）。其余 6 天是正常排法，可以当模板参考。

## 六、导入格式要点

一份文件可以放多周，两种命名都认：

```
第一周              ← 周总表
周一 周二 … 周日     ← 7 张日期子表，紧跟在这张周表后面
第二周
周一 周二 …
```

或者带日期：周总表叫 `本周计划` / `第06周本周计划`，子表叫 `10-18 周日`。

**多个文件的日期重叠会自动合并**，按「天」对齐、按「时间段 + 科目」合并条目，已经打过的勾不会被覆盖。比如先导 10/1-10/20，再导 10/10-10/25，中间那 11 天只保留一份。

更细的规则（包括哪些写法会让解析失败）在 `计划表导入格式_提示词.md` 里，那份文档同时也能直接发给 AI 让它生成计划。

## 七、数据存在哪

- 网页版：浏览器本地（localStorage），换浏览器或清缓存就没了
- 桌面版：`C:\Users\<你的用户名>\AppData\Roaming\Fairy`

两个都建议定期点「备份」导出一份 JSON 存着。清空数据有二次确认，不会误删。
